Concurrency

并行事件处理

同优先级处理器并行执行，不同优先级串行调度，Copy-On-Write 零开销，支持中断控制

pipeline.py 
@message.on_message(priority=10)
async def spam_filter(event):
    if is_spam(event.get_text()):
        event.done(claim=False)  # 仅阻断：低优先级不再执行

# 同优先级 → 并行执行，零拷贝
@message.on_message(priority=0)
async def handler_a(event):
    event['result_a'] = await process_a()

@message.on_message(priority=0)
async def handler_b(event):
    event['result_b'] = await process_b()
Flow Control

链路控制与事件覆写

done(claim, stop) 正交解耦认领与阻断，无需修改代码即可覆写任意模块的事件行为

overrides.py 
# done()：认领(claim) × 阻断(stop) 正交控制
@command("help")
async def help_cmd(event):
    event.done()                # 认领 + 阻断

@message.on_message(priority=50)
async def observer(event):
    event.done(stop=False)      # 仅认领：观察者仍可见

@message.on_message(priority=100)
async def firewall(event):
    if denied(event):
        event.done(claim=False) # 仅阻断：不破坏去重

# 不改代码，覆写任意模块行为
overrides.command.set("MyModule", "restart", master=True)
overrides.message.set("ChatModule", pattern="闲聊*")

Declarative

声明式配置与元信息

ConfigClass 声明式配置实时热读，get_meta 元信息接入 help 与仪表盘，activate_on 事件驱动懒激活

module.py 
class Main(BaseModule):
    @staticmethod
    def get_meta() -> ModuleMeta:
        return ModuleMeta(
            name="天气", description="查询城市天气",
            version="1.0.0", group="工具",
            tags=["天气", "查询"],
        )

    @staticmethod
    def get_load_strategy():
        return ModuleLoadStrategy(
            lazy_load=True,
            # 首个匹配命令/事件到达时自动激活
            activate_on=[{"command": {"name": "weather"}}],
        )
Ownership

归属权自动清理

在 on_load 内注册的资源自动记名归属，模块卸载时一键回收命令、处理器与后台任务，无需手动注销

lifecycle.py 
class Main(BaseModule):
    async def on_load(self, event):
        # 后台任务自动归属，卸载时自动取消
        self.task = self.spawn(self.polling())
        # 在 on_load 内注册才能被正确归属
        sdk.router.register_home_entry("我的模块", "/my")

    async def on_unload(self, event):
        ...  # 框架资源已被自动回收

Scope

统一作用域系统

从模块、身份、出站三个维度统一控制可用范围：配置即生效，支持热更新与 glob / 正则匹配

config.toml 
[ErisPulse.scope.platforms.onebot11]
modules = ["Chat", "Tool*"]   # 白名单：精确/glob/正则
blocked = ["re:^Danger"]

[ErisPulse.scope.identity.users.onebot11]
allow = ["u_admin"]
deny = ["spam_*"]

[ErisPulse.scope.actions.MyModule]
send = { deny = true }        # 全禁发送
api  = { allow = ["get_*"] }   # 仅允许查询类 API
Lifecycle Hooks

生命周期钩子

在框架运行的每个关键阶段插入自定义逻辑：模块加载、适配器启停、Bot 上下线，全程可监听可响应

Lifecycle Events 
@sdk.lifecycle.on("module.load")
async def on_loaded(data):
    sdk.logger.info(f"模块加载: {data}")

@sdk.lifecycle.on("adapter.bot.online")
async def on_bot_online(data):
    await notify_admin(f"Bot 上线: {data['bot_id']}")

@sdk.lifecycle.on("adapter.stop")
async def on_stop(data):
    sdk.logger.warning("适配器即将停止")
