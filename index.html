Core Architecture

事件驱动架构

所有交互通过事件传递，从平台接收到模块处理形成完整的异步事件流

handler.py 
@message.on_message()
async def handler(event):
    text = event.get_text()
    await event.reply(f"收到: {text}")
OneBot12 · Multi-Platform

多平台适配

一套代码同时对接云湖、Telegram、OneBot11/12、邮件等平台，适配器自动处理协议差异

OneBot12 标准兼容
multi.py 
@command("hello")
async def hello(event):
    # 云湖 · Telegram · QQ · 邮件...
    # 同一份代码，所有平台运行
    platform = event.get_platform()
    await event.reply(f"Hello from {platform}!")
Messaging Pipeline

链式发送与事件管线

SendDSL 链式发送、同优先级并行处理与 done(claim, stop) 链路控制，构成可组合、可覆写的异步事件管线

并行事件处理 链路控制与事件覆写
send.py 
# 规则组合：重试 + 超时 + 回调
await (adapter.Send.To("user", "123")
       .Retry(3).Timeout(10)
       .Hook(on_success)
       .OnError(on_error)
       .Text("可靠发送"))

# Build 批量构建：统一执行
await (adapter.Send.To("group", "G001")
       .Build()
       .Text("第一句").Image("pic.jpg")
       .send_all())

Modular

声明式配置与元信息
terminal 
# pip install ErisPulse-MyModule
# or: epsdk install MyModule

class Main(BaseModule):
    @staticmethod
    def get_load_strategy():
        return ModuleLoadStrategy(
            lazy_load=True,   # 首次访问时才初始化
            priority=10        # 数值越大越先加载
        )

    async def on_load(self, event):
        self.logger.info("模块已就绪")

Scope & Lifecycle

统一作用域与生命周期

从模块、身份、出站三个维度统一控制可用范围；在框架运行的每个关键阶段插入自定义逻辑，模块卸载时注册的资源自动归属回收

归属权自动清理 生命周期钩子
config.toml 
[ErisPulse.scope.platforms.onebot11]
modules = ["Chat", "Tool*"]   # 白名单：精确/glob/正则
blocked = ["re:^Danger"]

[ErisPulse.scope.identity.users.onebot11]
allow = ["u_admin"]
deny = ["spam_*"]

[ErisPulse.scope.actions.MyModule]
send = { deny = true }        # 全禁发送
api  = { allow = ["get_*"] }   # 仅允许查询类 API
