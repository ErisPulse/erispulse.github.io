ErisPulse.Core.Event.notice 模块

模块概述

ErisPulse 通知处理模块

提供基于装饰器的通知事件处理功能

提示

  1. 支持好友、群组等不同类型通知
  2. 支持成员变动等细粒度事件

类列表

class NoticeHandler

通知事件处理器

提供通知事件处理功能

返回值: 装饰器函数
