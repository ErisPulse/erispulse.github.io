開発者ガイド

Tip

このドキュメントを読むべきタイミング：ErisPulse 向けの拡張機能——ボットに機能を追加する（モジュール）や、新しいプラットフォームに接続する（アダプター）——を開発しようとしているとき。ボットを使いたいだけの場合はスキップして、クイックスタート を直接ご覧ください。

ここから自分の開発パスを見つけましょう：モジュール開発では、コマンドやメッセージハンドラーでボットの機能を拡張できます。アダプター開発では、ボットを新しいメッセージプラットフォームに接続できます。どちらのパスも、プロジェクトの作成からテスト、公開までの完全なフローをカバーしています。

  • リリースとモジュールストアガイド - あなたの作品を PyPI と ErisPulse モジュールストアに公開する方法

開発の準備

開発を始める前に、以下を確認してください：

  1. 基本概念 を読んでいること
  2. イベント処理 に慣れていること
  3. 開発環境（Python >= 3.10）をインストールしていること
  4. ErisPulse SDK をインストールしていること

開発タイプの選択

ニーズに合わせて適切な開発タイプを選択してください：

開発タイプ 適用シーン 入門ガイド
モジュール開発 ボット機能の拡張、ビジネスロジックの実装、コマンドとメッセージ処理の提供 モジュール開発入門
アダプター開発 新しいメッセージプラットフォームへの接続、クロスプラットフォーム通信の実現、プラットフォーム固有機能の提供 アダプター開発入門

ボットの機能を拡張したい場合（コマンドの追加、メッセージの処理など）は、モジュール開発を選択してください。ボットを新しいプラットフォームに接続する必要がある場合は、アダプター開発を選択してください。

プロジェクトテンプレート

ErisPulse は参考としてサンプルプロジェクトを提供しています：

  • モジュールのサンプル - モジュールの完全なプロジェクト構造
  • アダプターのサンプル - アダプターの完全なプロジェクト構造

開発モード

ホットリロードモードを使用して開発すると、コードの変更後に自動的にリロードされます：

epsdk run main.py --reload

デバッグのコツ

config/config.toml で DEBUG または TRACE レベルのログを有効にします：

[ErisPulse.logger]
# DEBUG: モジュールのロード、ルート登録などの開発デバッグ情報を出力
# TRACE: 最低レベル。イベントディスパッチ、ストレージ書き込み、遅延読み込みなどのフレームワーク内部の詳細なフローを出力
level = "DEBUG"
