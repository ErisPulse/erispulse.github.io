模块 访问路径 说明

sdk.adapter sdk.adapter 多平台适配器管理
sdk.module sdk.module 模块注册、加载、卸载管理
sdk.lifecycle sdk.lifecycle 生命周期事件管理
sdk.router sdk.router HTTP/WebSocket 路由管理
sdk.client sdk.client 统一 HTTP/WS 客户端

模块 导入路径 说明
