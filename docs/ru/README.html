Документация ErisPulse

ErisPulse — это масштабируемый многофункциональный фреймворк для обработки сообщений, поддерживающий взаимодействие с различными платформами через адаптеры и предоставляющий гибкую систему модулей для расширения функциональности.

Впервые используете? Просто посмотрите 5-минутное руководство — от установки до запуска первого бота, все шаги пройдены за один раз.

Выбор вашего пути

Выберите путь обучения в зависимости от ваших целей. Каждый путь представлен в порядке от простого к сложному.

Способы разработки

ErisPulse поддерживает два способа разработки:

  • Разработка модуля (рекомендуется): создание отдельного пакета модуля, устанавливаемого через менеджер пакетов, удобно для распространения и управления.
  • Встраиваемая разработка: непосредственное написание обработчиков в проекте, подходит для быстрого прототипирования. Подробнее см. Руководство.
