Документация ErisPulse

ErisPulse — это масштабируемый многофункциональный фреймворк для обработки сообщений, поддерживающий взаимодействие с различными платформами через адаптеры и предоставляющий гибкую систему модулей для расширения функциональности.

Впервые используете? Просто посмотрите 5-минутное руководство — от установки до запуска первого бота, все шаги пройдены за один раз.

Выберите свой путь

Выберите соответствующий путь обучения в зависимости от ваших целей. Внутри каждого пути темы расположены от простого к сложному.

3. Я хочу глубже понять принципы работы

Понимание внутренней работы фреймворка.

Документация Описание

Система адаптеров Регистрация, запуск, остановка адаптеров, вызов API
Основные модули Базовые возможности: Storage / Config / Logger / Router
Управление жизненным циклом · Ленивая загрузка · Система маршрутизации Внутренние подсистемы
Пул подключений и трансляция · Ящик сессий Ресурсы первого класса: трансляция / группировка / передача и повторное использование между модулями, просмотр пула подключений; стратегия сохранения и перезаписи сообщений
Область видимости (scope) Трехмерный контроль области видимости: доступность модуля, допуск событий, ограничение исходящих действий (включая мелкозернистые правила на уровне методов, наследование и объединение)
Система принадлежности (owner) Принадлежность ресурсов и автоматическая очистка: контекст owner, панорама принадлежащих ресурсов, последовательность очистки при выгрузке, границы проектирования и руководство для авторов модулей
Теневые модули и серый переход Новые версии модулей параллельно тестируются с отдельным owner: пять изоляционных барьеров, выравнивание поведения, переход на прод и откат при сбое
Система интерактивных сессий wait_reply полностью раскрыто, таймеры сессий (remind/escalate), многопоточные ожидания (select), взаимоисключающие сессии, ящик, транзакции сообщений, трассировка цепочки
Взаимодействие между модулями RPC-протокол (module.call),契约 meta.services и каталог, направленная отправка событий (emit(to=)), воспроизведение при холодном запуске,幂等ная дедупликация событий
Многошаговые диалоги Conversation · MessageBuilder · SQL-генератор · Хранилища · HTTP-клиент · Международная локализация Расширенные инструменты

Способы разработки

ErisPulse поддерживает два способа разработки:

  • Разработка модуля (рекомендуется): создание отдельного пакета модуля, устанавливаемого через менеджер пакетов, удобно для распространения и управления.
  • Встраиваемая разработка: непосредственное написание обработчиков в проекте, подходит для быстрого прототипирования. Подробнее см. Руководство.
