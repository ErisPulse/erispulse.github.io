ErisPulse-QvQChat — универсальный агент

Tip

Когда стоит читать этот документ: когда вы хотите добавить боту возможности ИИ-агента (цикл инструментов, потоковый диалог, MCP, долговременная память) или открыть службы своего модуля для вызова агентом. Если это не нужно — пропустите.

ErisPulse-QvQChat — это модуль универсального агента, построенный вокруг цикла инструментов: приём и отправка сообщений, вызов служб модулей экосистемы, написание и выполнение кода, управление компьютером, генерация изображений и речи, управление задачами по расписанию и долговременной памятью — всё выполняется через единый протокол инструментов.

Important

QvQChat требует отдельной установки:

epsdk install ErisPulse-QvQChat

Также необходимо добавить в «Пул моделей» хотя бы одну совместимую с OpenAI модель (Base URL, API Key, имя модели).

Расширение через модули

Любой модуль ErisPulse, объявляющий services, автоматически становится инструментом QvQChat — специальный интерфейс не требуется:

from ErisPulse.Core.Bases import BaseModule, ModuleMeta

class Main(BaseModule):
    @staticmethod
    def get_meta() -> ModuleMeta:
        return ModuleMeta(name="Draw", services=[
            {"name": "draw", "description": "Генерирует изображение по описанию, возвращает URL изображения"},
        ])

    async def draw(self, prompt: str, size: str = "1024x1024"):
        return {"image_url": "https://..."}

Сигнатуры методов служб автоматически отображаются в определения параметров JSON Schema инструмента, первая строка docstring используется как описание параметра.

Глубокая интеграция (опционально)

Модуль может дополнительно реализовать любые из следующих служб, каждая из которых независима и опциональна — модуль может заниматься только расширением персон или только внедрением промптов:

qvq_prompts() → внедрение системных промптов

Возвращает list[str] или list[{"text": str, "priority": int}], элементы объединяются в порядке возрастания priority.

async def qvq_prompts(self):
    return [
        {"text": "После создания изображения отправьте его пользователю через send_message.", "priority": 10},
        {"text": "Поддерживаемые стили: аниме, реализм, акварель, пиксель-арт.", "priority": 20},
    ]

qvq_personas() → регистрация предустановок персон

Возвращает список персон, к id автоматически добавляется префикс ext.<имя модуля>., при удалении модуля выполняется автоматическая очистка. Подходит для модулей, специализирующихся на расширении персон (эмоциональный компаньон, переводчик, рецензент кода и т.д.).

async def qvq_personas(self):
    return [
        {"id": "companion", "name": "Тёплый собеседник", "system": "Ты — тёплый и заботливый собеседник..."},
        {"id": "coder", "name": "Наставник по коду", "system": "...", "tools": ["read_file", "run_python"]},
    ]

tools опционально ограничивает подмножество инструментов, доступных данной персоне.

qvq_schemas() → явные схемы параметров

Возвращает dict[имя службы, JSON Schema], переопределяя вывод из сигнатуры метода. Используется, когда параметры сложны или требуется строгая валидация.

async def qvq_schemas(self):
    return {
        "draw": {
            "type": "object",
            "properties": {
                "prompt": {"type": "string", "description": "Описание изображения"},
                "size": {"type": "string", "enum": ["512x512", "1024x1024"]},
            },
            "required": ["prompt"],
        },
    }

Моменты обновления

Моменты обновления служб глубокой интеграции: запуск, установка и удаление модулей, ручное обновление на странице «Инструменты» в Dashboard.

Подписка на события

QvQChat рассылает два события жизненного цикла:

Событие Момент Полезная нагрузка
qvq.message Получено сообщение пользователя chat_key platform sender_id sender_name text is_group
qvq.replied После отправки ответа chat_key reply tools 
async def setup(self):
    sdk.lifecycle.on("qvq.message", self.on_message)

Вызов в качестве службы

Служба Сигнатура Описание
chat (session_id, prompt, persona="") Диалог с агентом, возвращает текст
run_prompt (chat_key, prompt, ...) Запускает промпт, результат может быть отправлен в целевую сессию
get_status () Сводка состояния выполнения

Сопутствующие плагины

Три независимых модуля расширяют QvQChat и заодно демонстрируют, на что способны точки расширения — после установки QvQChat добавляйте их по мере необходимости:

Плагин Что делает
ErisPulse-QvQStalker Подслушивает групповые чаты и автоматически вмешивается в разговор: отслеживание активности, пятиуровневая оценка и уровень импульсивности совместно определяют, когда агенту вступить; 15 параметров поведения настраиваются прямо на странице настроек
ErisPulse-QvQMemes Прививает агенту привычку к мемам и стикерам: инструмент send_sticker позволяет модели самой выбирать, какой стикер отправить, изображения из групповых чатов автоматически собираются и размечаются визуальной моделью
ErisPulse-QvQCompanion Антропоморфное сопровождение: внедрение персоны и тона общения, инициативные реплики по уровню импульсивности, периоды тишины и дневной лимит

Все три плагина подключаются через соглашения о службах, описанные выше в разделе «Расширение через модули», и сами являются эталонной реализацией написания расширений.

Интерфейс

Доступен отдельно по адресу /QvQChat/view или встроен в боковую панель Dashboard.

  • Подпишитесь на сообщения агента для интеграции: слушайте qvq.message / qvq.replied с помощью событий жизненного цикла
  • Не нужен агент, а нужна лишь многошаговая форма вопросов и ответов: встроенный Conversation — многошаговый диалог — более лёгкое решение
  • Управление через веб-интерфейс: используйте вместе с боковой панелью ErisPulse-Dashboard
