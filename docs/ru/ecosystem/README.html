Экосистемные модули

Сама платформа ErisPulse предоставляет только основные возможности (система событий, система модулей, конфигурация, маршрутизация, логирование и т.д.), не включая в себя GUI, рендеринг изображений, визуализацию и другие "тяжелые" функции. Эти возможности предоставляются третьими сторонами, поддерживаемыми сообществом, и устанавливаются по мере необходимости.

Important

Документация в этом разделе разделена на два типа, с разными способами установки:

  • Модули (например, Dashboard / Takumi) устанавливаются с помощью epsdk install:

    epsdk install <имя_модуля>

  • Отдельные программы (например, клиент ErisPulse-App) устанавливаются напрямую из соответствующих GitHub Releases, без использования epsdk.

Рекомендуемые модули и официальные клиенты

Проект Тип Назначение Документация
ErisPulse-App Официальный клиент Официальный клиент для всех платформ (Android / Windows / Linux / macOS): создание / запуск / управление несколькими экземплярами с помощью нативного интерфейса, встроенный магазин модулей и конструктор событий; прямой запуск на телефоне, автозапуск в трее на рабочем столе Установка и использование ErisPulse-App
ErisPulse-Dashboard Модуль Веб-панель управления: включение / отключение модулей, редактирование конфигураций, просмотр логов, мониторинг событий; поддержка регистрации пользовательских окон в боковой панели другими модулями Использование Dashboard и регистрация окон
ErisPulse-Cron Модуль Планировщик задач: однократные / периодические / по выражению Cron, передача параметров в обратный вызов, SQLite-хранилище (задачи не теряются при перезапуске), поддержка управления через окно Dashboard Cron-планировщик задач
ErisPulse-Takumi (автор @ccd2s) Модуль Генерация изображений: HTML / дерево узлов / Jinja / SVG / анимация, основан на takumi-py; встроенные шрифты на китайском и английском, готов к использованию без дополнительной настройки Генерация изображений Takumi

Я тоже хочу добавить свой модуль сюда?

Добро пожаловать, чтобы рекомендовать качественные и широко используемые модули экосистемы ErisPulse. Требования:

  1. Опубликован на PyPI и имя пакета начинается с ErisPulse-
  2. Предоставляет базовый README и примеры использования
  3. Активно поддерживается, есть ответы на Issue

Авторы модулей, соответствующих вышеуказанным условиям, могут добавить в этот каталог документ <имя_модуля>.md через PR и добавить строку в таблицу "Рекомендуемые модули".
