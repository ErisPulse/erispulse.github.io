ErisPulse.runtime.reload_ops 模块

模块概述

热重载操作协调器

reload / restart / 归眠（sleep）共享的全局互斥与 restart 风暴合并：

  • 互斥：单模块重载 / 全量重载 / 适配器重载 / 归眠全程持同一把锁。

    重载共享注册表快照单槽（_last_module_objs）、finder 缓存、 sys.modules purge 与级联闭包，按模块名分锁无法保护这些共享资源； 重载是运维触发型操作（保存文件 / 手动命令），串行化无性能代价， watcher 风暴下串行正是期望行为。

  • 重入直通：已持锁任务内再触发重载（如模块 on_unload 钩子内调用

    sdk.reload_module）直接执行——调用方已在串行管线内，同任务内再入 不会与其它重载并发。

  • restart 合并：restart 进行中再收到 restart 请求时置 dirty 标记并

    立即返回（合并），持锁任务每轮结束后检查 dirty 并补跑一轮——保存 风暴至多引起「一轮完整重载 + 一轮补跑」，绝不并发交叉。restart 请求落在普通 reload / 归眠持锁期间时同样合并：首个请求登记 deferred 标记并排队等锁，后续请求直接并入（否则 N 个请求会串行执行 N 轮完整 restart）。

async run_reload_exclusive(fn: 'Callable[[], Awaitable[_T]]') -> _T

在热重载全局互斥下执行 fn（重入直通）

所有重载入口（单模块 / 全量 / 适配器 / restart 内部管线）统一经本 函数进入：并发触发自动串行；已持锁任务内重入（如 on_unload 钩子内再触发重载）直接执行避免自锁。

  • fn: 待执行的无参协程工厂

返回值 (fn): 的返回值

示例:

await run_reload_exclusive(lambda: loader.reload_module("dice", m, s))

async run_reload_exclusive_bounded(fn: 'Callable[[], Awaitable[_T]]', *, timeout: float, warn_log_key: str, log_params: 'dict[str, Any] | None' = None) -> _T

限时等待热重载互斥后执行 fn；超时降级为直接执行（warning 留痕）

供不可跳过的公共入口（module.unload() / adapter.unload()） 使用：常规情况下与 reload / restart / 归眠串行（消除外部卸载与重载 交叉导致的双重 on_unload）；持锁重载长时间卡死的极端场景下不 永久阻塞调用方（降级为无锁直行）。重入直通语义与 :func:run_reload_exclusive 一致——重载管线内部调用零开销。

  • fn: 待执行的无参协程工厂
  • timeout: 等锁超时（秒）——只限锁等待，不限 fn 本身执行
  • warn_log_key: 超时降级的 warning 文案键
  • log_params: 日志参数

返回值 (fn): 的返回值

类列表

class ReloadOpsCoordinator

内部方法 热重载操作的全局互斥锁与 restart 合并状态机

状态机:

IDLE ──restart()──► RUNNING ──完成──┬─ dirty=0 → 释放锁（IDLE）
             │restart()             └─ dirty=1 → 置0，补跑一轮（RUNNING）
             ▼
         dirty=True（记「已合并」日志）

IDLE ──reload 持锁──► LOCKED(BY-RELOAD) ──restart()──► deferred=True，
调用方调度 ``_do_restart`` 排队等锁；期间后续 restart() 直接并入；
获得锁后 deferred 清零，与常规 restart 轮同流程。

reload_module / reload_adapter / reload_all / sleep 不 参与 dirty 状态机——晚到的文件改动必须真正执行，不能靠「restart 已 覆盖」推断丢弃（改动可能发生在 restart 读取文件之后），它们只在锁上 排队等待。

示例:

from ErisPulse.runtime.reload_ops import run_reload_exclusive
result = await run_reload_exclusive(lambda: loader.reload_module(...))
