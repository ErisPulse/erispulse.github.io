Документация по функциям платформы Sandbox

SandboxAdapter — это встроенный адаптер песочницы ErisPulse, предназначенный для локальной разработки и отладки модулей — позволяет моделировать отправку и получение сообщений без необходимости использования реальной платформы.

Информация о документации

  • Версия соответствующего модуля: 4.1.0
  • Ответственный: ErisPulse

Основная информация

  • Описание платформы: Локальная среда песочницы, предоставляющая виртуальных пользователей/группы, веб-панель отладки и сохранение сообщений
  • Название адаптера: SandboxAdapter
  • Идентификатор платформы: sandbox
  • Дизайн для одной учетной записи (сценарий локальной отладки)
  • Требования к фреймворку: Опциональная зависимость ErisPulse>=2.7.1 (проверка во время выполнения с подсказкой, не обязательна)

Обновление парадигмы v5 (4.1.0)

  • Минимальный набор Api DSL: get_self_info / get_status / get_version / get_supported_actions
  • Принадлежность задачи spawn_background: задача "heartbeat" теперь использует runtime.spawn_background
  • Мягкие зависимости фреймворка: проверка наличия ErisPulse>=2.7.1 и вывод предупреждения
  • Обновление путей импорта до Core.Bases (BaseConfig)

Примеры стандартных API-действий

from ErisPulse import sdk
sandbox = sdk.adapter.get("sandbox")

result = await sandbox.Api.get_self_info()   # Информация о боте в песочнице
result = await sandbox.Api.get_status()
result = await sandbox.Api.get_supported_actions()

Инструкция по использованию

  • Сэндбокс предоставляет виртуальных пользователей и группы, модули могут отправлять и получать сообщения, как на реальной платформе
  • Веб-панель отладки позволяет вручную отправлять сообщения для запуска логики обработки модуля
  • Данные сообщений сохраняются в постоянном хранилище, восстанавливаются после перезапуска
