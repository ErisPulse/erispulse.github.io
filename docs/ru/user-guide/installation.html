Справочник по установке

В этой статье представлен полный справочник по установке (pip / uv / Docker / устранение неполадок). Если вы хотите быстро запустить, быстрый старт за 5 минут уже охватывает самый простой процесс.

Требования к системе

  • Python 3.10 или выше
  • pip или uv (рекомендуется)
  • Достаточное свободное место на диске (не менее 100 МБ)

Способы установки

Способ 1: Установка с помощью pip

# Установка ErisPulse
pip install ErisPulse

# Обновление до последней версии
pip install ErisPulse --upgrade

Способ 2: Установка с помощью uv (рекомендуется)

uv — это более быстрая Python-инструментальная цепочка, рекомендуемая для среды разработки.

Установка uv

# Установка uv с помощью pip
pip install uv

# Проверка установки
uv --version

Создание виртуального окружения

# Создание каталога проекта
mkdir my_bot && cd my_bot

# Установка Python 3.12
uv python install 3.12

# Создание виртуального окружения
uv venv

Активация виртуального окружения

# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate

Установка ErisPulse

# Установка ErisPulse
uv pip install ErisPulse --upgrade

Способ 3: Установка с помощью uv tool (глобальный CLI, рекомендуется)

Если вы хотите использовать epsdk как глобальный командную строку, uv tool install — самый чистый способ: epsdk работает в независимой среде инструментов, не загрязняя любые проектные окружения:

# Установка (epsdk сразу доступен, без необходимости активации виртуального окружения)
uv tool install ErisPulse

# Обновление (или просто используйте epsdk self-update, автоматически будет использоваться этот канал)
uv tool upgrade ErisPulse

Note

В среде инструментов epsdk автоматически распознает .venv проекта при запуске в каталоге проекта: epsdk install установит компоненты в проектное окружение, а epsdk run будет использовать проектное окружение для запуска робота, при этом сам фреймворк по-прежнему предоставляется средой инструментов, и обе стороны не влияют друг на друга.

Инициализация проекта и установка модулей

После завершения установки, полный процесс инициализации проекта, установки модулей и запуска описан в 5-минутном кратком руководстве.

Способ 3: Использование клиентского приложения ErisPulse-App (без терминала)

Не хотите устанавливать среду Python? ErisPulse-App — это официальное клиентское приложение для всех платформ (Android / Windows / Linux / macOS), которое можно запускать напрямую с телефона, а десктопная версия поддерживает сворачивание в системную панель для постоянной работы в фоне; включает в себя Python-интерпретатор и SDK ErisPulse, не требуя терминала и ручной настройки:

  • Скачайте приложение с GitHub Releases, выбрав нужный файл в зависимости от вашей платформы (для Android online/offline APK, для Windows setup.exe/zip, для Linux tar.gz, для macOS zip)
  • Создайте и запустите экземпляр в приложении, управляйте адаптерами и модулями через родной интерфейс, просматривайте магазин модулей

Подробное описание см. в установке и использовании ErisPulse-App.

Проверка установки

Проверка установки

# Проверка версии ErisPulse
epsdk --version

Запуск теста

# Запуск проекта
epsdk run main.py

Если вы видите подобный вывод, значит установка прошла успешно:

[INFO] Инициализация ErisPulse...
[INFO] Загружен адаптер: Yunhu
[INFO] Загружен модуль: MyModule
[INFO] Инициализация ErisPulse завершена

Часто задаваемые вопросы

Ошибка установки

  1. Проверьте, что версия Python >= 3.10 (рекомендуется 3.10 - 3.14; сборка 3.14t free-threaded без GIL временно не поддерживается, фреймворк продолжает экспериментально мониторить CI-сборки)
  2. Попробуйте использовать uv pip install ErisPulse вместо pip install
  3. Если возникает ошибка прав доступа, попробуйте pip install --user ErisPulse или используйте виртуальное окружение
  4. Если в корпоративной среде с прокси-сервером возникает ошибка SSL-сертификата, попробуйте pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org ErisPulse
  5. Убедитесь, что сетевое подключение работает нормально, и что репозиторий pip доступен

Ошибка конфигурации

  1. Проверьте синтаксис файла config.toml (формат TOML чувствителен к отступам и кавычкам)
  2. Убедитесь, что все необходимые параметры конфигурации заполнены
  3. Просмотрите логи терминала для получения подробной информации об ошибке
  4. Используйте epsdk init для повторного создания конфигурационного файла

Ошибка установки модуля

  1. Убедитесь, что имя модуля написано правильно (регистр букв имеет значение)
  2. Проверьте сетевое подключение
  3. Используйте epsdk list-remote, чтобы просмотреть список доступных модулей
  4. Убедитесь, что модуль совместим с текущей версией SDK

Стратегия выполнения PowerShell в Windows

Если PowerShell выдает сообщение "Невозможно загрузить файл... так как выполнение скриптов запрещено на этой системе":

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Ошибка создания виртуальной среды в Debian/Ubuntu

Если скрипт установки сообщает "Ошибка создания виртуальной среды", и в сообщении об ошибке содержится ensurepip is not available, это означает, что python3-venv не установлен по умолчанию в Debian/Ubuntu (встроенный ensurepip для системного Python отключен):

sudo apt install python3.13-venv   # Установите пакет, соответствующий вашей версии Python
# или установите универсальный метапакет:
sudo apt install python3-venv

После установки повторно запустите скрипт установки. Новые версии скрипта установки автоматически обнаруживают эту проблему, предлагают установить соответствующий системный пакет и могут выполнить установку автоматически. Также вы можете использовать uv (команда uv venv не зависит от ensurepip).
