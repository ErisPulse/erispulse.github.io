高級主題

本目錄包含 ErisPulse 框架的高級特性與深入主題。

文件列表

  • 啟動流程與手動控制 - 啟動鏈路拆解（Finder/Loader/Manager/Router）與手動完整啟動
  • 懶加載系統 - 懶加載模組系統的工作原理、配置與事件驅動懶激活（activate_on）
  • 作用域（scope） - 三維作用域控制：模組可用性 / 事件准入 / 出站動作限制（含方法級細粒度規則與綁定繼承 merge）
  • 歸屬權（owner）系統 - 資源歸屬與自動回收：owner 上下文機制、歸屬資源全景、卸載清理序列與設計邊界
  • 影子模組與灰度轉正 - 模組新版本獨立 owner 並行試運行：出站拦截記帳、行為 diff 對比、promote 轉正與失敗回滾
  • 互動會話系統 - wait_reply / 會話定時器 / 多路等待 / 會話互斥租約 / 收件箱 / 消息事務 / 鏈路追蹤
  • 模組間通信 - RPC 協議化（module.call）、服務契約與目錄、定向事件、冷啟動回放、事件冪等去重
  • 國際化 (i18n) - 多語言支援、翻譯註冊與語言檢測
  • 生命週期管理 - 生命週期事件系統的使用方法
  • 路由管理器 - HTTP 和 WebSocket 路由管理
  • HTTP 客戶端 - 統一 HTTP 請求客戶端
  • MessageBuilder 詳解 - OneBot12 消息段建構器的雙模式用法
  • SQL 查詢建構器 - 通用 SQL 鏈式查詢建構器及儲存後端抽象
  • 儲存後端 - sqlite / mysql / postgres 異步原生存儲後端的選擇、配置與切換
  • 異常體系與捕獲指南 - 框架全部異常類型、發生位置與捕獲建議
  • 會話類型系統 - 會話類型定義、映射與自定義類型註冊
  • Conversation 多輪對話 - 多輪對話上下文的互動方法

Note


Dashboard 視窗註冊、Takumi 圖片渲染等 第三方生態模組 的文件已遷移至 生態模組 目錄。

適用對象

這些文件適合以下開發者：

  • 已經熟悉 ErisPulse 基礎功能的開發者
  • 需要深入理解框架內部機制的開發者
  • 需要優化性能或實現複雜功能的開發者
