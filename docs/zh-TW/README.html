ErisPulse 文件

ErisPulse 是事件驅動的模組化非同步機器人框架——業務程式碼只寫一次，透過適配器部署到 QQ、Telegram、Kook、雲湖等多個平台，插件系統、熱重載與完整的開發者工具鏈開箱即用。

第一次使用？ 直接看 5 分鐘快速入門 —— 從安裝到執行第一個機器人，一氣呵成。

按場景分組（按需查閱）

分組 文件 不懂首篇會踩的坑
運行啟動 啟動流程與手動控制 · 懶加載 不懂啟動鏈路（Finder / Loader / Manager / Router），模組加載失敗時只能對著日誌干瞪眼
通信連接 模組間通信 · 連接池與廣播 · 路由系統 不懂服務契約（meta.services）白名單，跨模組 module.call 會被 ServiceNotProvidedError 拒絕且不知原因
數據存儲 存儲後端 · SQL 構建 · HTTP 客戶端 不懂連接失敗冷卻期語義，數據庫抖動時會誤判"框架掛了"（實際是存儲操作快速失敗、冷卻後自動重連）
消息對話 Conversation 多輪對話 · 會話收件箱 · MessageBuilder · 國際化 不懂會話互斥租約，兩個模組同時等同一用戶的回覆會互相踢掉
灰度影子 影子模組與灰度轉正 不懂五道隔離閘就提前轉正，影子的出站消息會外溢到真實用戶

概念關係總表

分不清哪個子系統管什麼時，按這張表對號入座：

子系統 回答什麼問題 一句話口訣
通信（module-communication） 模組之間怎麼互相調用、怎麼定向發事件？ 跨模組走 module.call；對方聲明了 meta.services 就只能調白名單內的方法
權限（scope） 誰能用這個模組、誰能觸發事件、能執行哪些動作？ 三道閘——模組綁定、身份准入、出站限制，全部由用戶配置說了算
歸屬（ownership） 模組卸載後，它開的連接、定時器、訂閱去哪了？ 誰註冊誰歸屬，卸載即回收，不留懸掛資源
懶加載與休眠（lazy-loading） 模組什麼時候才真正加載、閒置後去哪？ activate_on 用到才醒，dormant_after 閒置歸眠
互動（interaction） 怎麼等用戶下一條回覆、多輪收集怎麼寫？ wait_reply 等一條、.got() 鏈收多輪，租約保證不打架
影子灰度（shadow） 新版模組怎麼在不影響線上的情況下試運行？ 影子收副本、出站只記賬，promote 由人確認才轉正
存儲（storage-backends） 數據存哪、後端怎麼換？ 同一套存儲 API，sqlite / mysql / postgres 配置切換

2.7 生產化基座：OneBot12 標準化基類（ApiDSL / BaseConverter）、配置熱更新系統化、優雅關閉與 SIGTERM/SIGHUP 信號處理、環境變數配置覆蓋、生命週期回調鉤子、Web 栈懶加載；2.7.1 修補配置寫入可靠性和 GC 分代治理

2.9 「模組開發體驗」主線（EPRFC-2026-001）：宣告式命令參數（args= / options=）與命令治理（cooldown= / rate_limit=）、統一依賴注入（Depends）、中間件事件否決權、內建 ORM（自動遷移 + 關係映射）、影子模組灰度轉正、分發決策鏈追蹤與排查診斷、正式支援 Python 3.14
2.10 連接一等資源（connections 註冊表：廣播 / 業務分組 / 跨模組傳遞複用 / 卸載自動回收）、根導入契約（常用 API 全部可 from ErisPulse import）、歸屬權體系補全、收件箱保留策略執行時覆蓋；2.10.2 適配器本地插件目錄（plugins/）+ epsdk create pack + tomlclass 無損配置寫入
2.11（dev） 「改代碼 → 看效果」開發閉環：熱重載預設全量語義（語法預檢 + 代碼身份核對 + 依賴者級聯重導）、懶加載休眠（dormant_after）、適配器代碼級熱重載（sdk.adapter.reload）、.got() 命令流語法糖、epsdk stop / restart 運行時控制
