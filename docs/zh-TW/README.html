ErisPulse 文件

ErisPulse 是一個可擴展的多平台訊息處理框架，支援透過適配器與不同平台互動，提供靈活的模組系統用於功能擴展。

第一次使用？ 直接看 5 分鐘快速入門 —— 從安裝到執行第一個機器人，一氣呵成。

開發方式

ErisPulse 支援兩種開發方式：

  • 模組開發（推薦）：建立獨立的模組套件，透過套件管理工具安裝，便於分發與管理。
  • 內嵌式開發：直接在專案中編寫處理器，適合快速原型。詳見 快速入門。

其他

  • 文件風格指南 — 貢獻文件時的寫作規範
  • 為 ErisPulse 貢獻 — 參與項目共建的入口
  • AI 輔助開發 — 獲取供 AI 編程助手使用的專案提示詞
