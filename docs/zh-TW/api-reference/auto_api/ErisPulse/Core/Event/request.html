ErisPulse.Core.Event.request 模块

模块概述

ErisPulse 请求处理模块

提供基于装饰器的请求事件处理功能

提示

  1. 支持好友请求、群邀请等不同类型请求
  2. 在处理器中可通过 event.approve() 同意请求或 event.reject() 拒绝请求
  3. 请求事件必须包含 request_id 字段才能执行操作

类列表
