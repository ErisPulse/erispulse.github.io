ErisPulse.Core.Bases.manager 模块

模块概述

ErisPulse 管理器基类

提供适配器和模块管理器的统一接口定义

提示 适配器管理器和模块管理器都应继承此基类以保持接口一致性

类列表

class ManagerBase(ABC)

管理器基类

定义适配器和模块管理器的统一接口

提示 统一方法：

  • register(): 注册类
  • unregister(): 取消注册
  • get(): 获取实例
  • exists(): 检查是否存在
  • enable()/disable(): 启用/禁用
  • is_enabled(): 检查是否启用
  • is_running(): 检查是否运行
  • list_*(): 列出相关项

方法列表

register(name: str, class_type: type, info: dict | None = None)

注册类

  • name (名称): - class_type: 类类型
  • info (额外信息): 返回值: 是否注册成功
unregister(name: str)

取消注册

  • name (名称): 返回值: 是否取消成功
get(name: str)

获取实例

  • name (名称): 返回值 (实例或): None
exists(name: str)

检查是否存在（在配置中注册）

  • name (名称): 返回值: 是否存在
is_enabled(name: str)

检查是否启用

  • name (名称): 返回值: 是否启用
enable(name: str)

启用

  • name (名称): 返回值: 是否成功
disable(name: str)

禁用

  • name (名称): 返回值: 是否成功
list_registered()

列出所有已注册的项

返回值: 名称列表

list_items()

列出所有项及其状态

返回值 ({名称:): 是否启用} 字典

is_running(name: str)

检查项是否正在运行

对于适配器：检查是否已启动 对于模块：检查是否已加载

  • name (名称): 返回值: 是否正在运行
list_running()

列出所有正在运行的项

对于适配器：列出所有已启动的适配器 对于模块：列出所有已加载的模块

返回值: 名称列表
