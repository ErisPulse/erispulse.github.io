快速參考

常用命令

命令 說明
epsdk init 初始化專案（-q 快速模式，-n 指定名稱）
epsdk install <包名> 安裝模組/適配器（不帶參數進入互動模式）
epsdk config <名稱> 互動式配置適配器/模組的宣告式配置項
epsdk run main.py 運行專案（--reload 熱重載模式）
epsdk list 列出已安裝的模組/適配器
epsdk upgrade <包名> 升級模組/適配器
epsdk doctor 診斷環境（Python/後端/配置/PyPI 連通性）

完整的命令列表和參數說明請參考 CLI 命令參考。

常見配置位置

配置項 說明 詳見
[ErisPulse.server] 伺服器配置（主機、端口） 配置文件說明
[ErisPulse.logger] 日誌配置（等級、輸出檔案） 配置文件說明
[ErisPulse.framework] 框架配置（懶加載） 配置文件說明
[ErisPulse.event.command] 命令事件配置（前綴） 配置文件說明
[適配器名] 各適配器的特定配置 平台特性指南
