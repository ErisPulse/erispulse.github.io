ErisPulse 文档

ErisPulse 是事件驱动的模块化异步机器人框架——业务代码只写一遍，通过适配器部署到 QQ、Telegram、Kook、云湖等多个平台，插件系统、热重载与完整开发者工具链开箱即用。

第一次使用? 直接看 5 分钟快速开始 —— 从安装到运行第一个机器人，一条龙走完。

根据你的目标，选择对应的学习路径。每条路径内部按由浅入深排列。

概念关系总表

分不清哪个子系统管什么时，按这张表对号入座：

子系统 回答什么问题 一句话口诀
通信（module-communication） 模块之间怎么互相调用、怎么定向发事件？ 跨模块走 module.call；对方声明了 meta.services 就只能调白名单内的方法
权限（scope） 谁能用这个模块、谁能触发事件、能执行哪些动作？ 三道闸——模块绑定、身份准入、出站限制，全部由用户配置说了算
归属（ownership） 模块卸载后，它开的连接、定时器、订阅去哪了？ 谁注册谁归属，卸载即回收，不留悬挂资源
懒加载与休眠（lazy-loading） 模块什么时候才真正加载、闲置后去哪？ activate_on 用到才醒，dormant_after 闲置归眠
交互（interaction） 怎么等用户下一条回复、多轮收集怎么写？ wait_reply 等一条、.got() 链收多轮，租约保证不打架
影子灰度（shadow） 新版模块怎么在不影响线上的情况下试运行？ 影子收副本、出站只记账，promote 由人确认才转正
存储（storage-backends） 数据存哪、后端怎么换？ 同一套存储 API，sqlite / mysql / postgres 配置切换

开发方式

ErisPulse 支持两种开发方式：

  • 模块开发（推荐）：创建独立的模块包，通过包管理器安装，便于分发和管理。
  • 嵌入式开发：直接在项目中编写处理器，适合快速原型。详见 快速开始。

其他

  • 文档风格指南 — 贡献文档时的写作规范
  • 为 ErisPulse 贡献 — 参与项目共建的入口
  • AI 辅助开发 — 获取供 AI 编程助手使用的项目提示词
