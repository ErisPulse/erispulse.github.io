ErisPulse 文档

ErisPulse 是一个可扩展的多平台消息处理框架，支持通过适配器与不同平台交互，提供灵活的模块系统用于功能扩展。

第一次使用? 直接看 5 分钟快速开始 —— 从安装到运行第一个机器人，一条龙走完。

开发方式

ErisPulse 支持两种开发方式：

  • 模块开发（推荐）：创建独立的模块包，通过包管理器安装，便于分发和管理。
  • 嵌入式开发：直接在项目中编写处理器，适合快速原型。详见 快速开始。
