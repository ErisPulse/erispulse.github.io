ErisPulse.Core.Event.meta 模块

模块概述

ErisPulse 元事件处理模块

提供基于装饰器的元事件处理功能

提示

  1. 支持连接、断开连接等生命周期事件
  2. 适用于系统状态监控和初始化操作

类列表

class MetaHandler

元事件处理器

提供元事件处理功能，如连接、断开连接等
