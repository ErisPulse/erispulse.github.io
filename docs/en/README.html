ErisPulse Documentation

ErisPulse is an extensible, multi-platform message processing framework that supports interaction with various platforms through adapters, providing a flexible module system for functional extension.

First time using? Just check out the 5-Minute Quick Start —— from installation to running your first bot, all in one go.

Choose Your Path

Based on your goals, select the corresponding learning path. Each path is arranged from basic to advanced.

Important

You don't need to read all documents. Most developers only need to read the L1 Core Five (about 1–2 hours) to independently develop 90% of features; the rest are on-demand reference materials for specific scenarios — read them when you encounter the corresponding needs. Each document starts with a note indicating "When do you need to read this."

L1 Core Five: Getting Started with Module Development → Basic Concepts → Event Wrapper Class → Configuration File Guide → Exception Handling

Adapter authors also need: Getting Started with Adapter Development → Event Converter → Detailed SendDSL Guide

Development Methods

ErisPulse supports two development methods:

  • Module Development (Recommended): Create independent module packages and install them via the package manager, which facilitates distribution and management.
  • Embedded Development: Write processors directly within the project, suitable for rapid prototyping. See Quick Start.
