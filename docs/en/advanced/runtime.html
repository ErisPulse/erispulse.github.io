The runtime Toolbelt

Tip

When to read this: When you want a one-stop overview of the runtime tools that the ErisPulse.runtime package provides for direct import. Detailed usage of each capability lives in its corresponding topic documentation; this page serves as a quick-reference index plus usage notes for a few capabilities without a dedicated topic.

ErisPulse.runtime is the framework's aggregated export layer: it gathers runtime tools scattered across modules into a single entry point, so scripts, modules, and adapter code uniformly use from ErisPulse.runtime import X, without needing to remember deep import paths.

dict_to_dataclass: dict → Type-Safe Objects

The "reverse direction" of declarative dataclass configuration — parse any dict (API responses, webhook payloads, user input) into type-safe instances according to declarations, replacing hand-written data.get("x", default) chains:

from dataclasses import dataclass, field
from ErisPulse.runtime import dict_to_dataclass

@dataclass
class WebhookPayload:
    order_id: str
    amount: float = 0.0
    tags: list = field(default_factory=list)
    remark: str = ""

payload = dict_to_dataclass(WebhookPayload, {
    "order_id": "A-1024",
    "amount": "99.5",           # str → float auto-converted
    "unknown_key": "ignored",   # undeclared fields are automatically ignored
})
payload.amount                  # 99.5 (float)
  • Type conversion (str → int/float, etc.), default value filling, and recursive filling of nested dataclasses
  • Environment variable override: when a field declares metadata={"env": "NAME"}, the priority order is environment variable > data > default value
  • The hot-reload callback of declarative configuration classes (ConfigClass / BaseConfig) internally uses it to perform the dict → config object conversion
