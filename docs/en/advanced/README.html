Advanced Topics

This directory contains advanced features and in-depth topics of the ErisPulse framework.

Documentation List

  • Startup Process and Manual Control - Breakdown of the startup chain (Finder/Loader/Manager/Router) and manual full startup
  • Lazy Loading System - Working principles, configuration, and event-driven lazy activation (activate_on) of the lazy loading module system
  • Scope - Three-dimensional scope control: module availability / event access / outbound action restrictions (including method-level fine-grained rules and binding inheritance merge)
  • Ownership System - Resource ownership and automatic cleanup: owner context mechanism, ownership resource overview, unload cleanup sequence, and design boundaries
  • Shadow Modules and Gray Release Promotion - Parallel trial run of new module versions with independent owner: outbound interception accounting, behavior diff comparison, promote promotion and rollback on failure
  • Interaction Session System - wait_reply / session timer / multi-path waiting / session mutual exclusion lease / inbox / message transaction / trace linking
  • Inter-Module Communication - RPC protocol (module.call), service contracts and directory, directed events, cold start replay, event idempotency deduplication
  • Internationalization (i18n) - Multi-language support, translation registration, and language detection
  • Lifecycle Management - Usage methods of the lifecycle event system
  • Router Manager - HTTP and WebSocket routing management
  • HTTP Client - Unified HTTP request client
  • MessageBuilder Detailed Explanation - Dual-mode usage of the OneBot12 message segment builder
  • SQL Query Builder - General SQL chain query builder and storage backend abstraction
  • Storage Backends - Selection, configuration, and switching of asynchronous native storage backends: sqlite / mysql / postgres
  • Exception System and Handling Guide - All framework exception types, occurrence locations, and handling recommendations
  • Session Type System - Session type definitions, mapping, and custom type registration
  • Conversation Multi-turn Dialogue - Interaction methods of multi-turn dialogue context

Note

Documentation for third-party ecosystem modules such as Dashboard view registration and Takumi image rendering has been migrated to the Ecosystem Modules directory.

Intended Audience

These documents are suitable for the following developers:

  • Developers who are already familiar with the basic features of ErisPulse
  • Developers who need to deeply understand the internal mechanisms of the framework
  • Developers who need to optimize performance or implement complex features

Prerequisites

Before reading the documents in this directory, it is recommended to first understand:

  • Basic Concepts
  • Event Handling Introduction
  • Module Development Guide
